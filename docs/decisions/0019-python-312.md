# ADR-0019: Python 3.12 for everyone and CI

- **Status:** Accepted
- **Date:** 2026-10-31
- **Deciders:** team
- **Supersedes:** none

## Context

Different Python versions across three laptops cause "works on my machine" bugs, and the newest Python version sometimes lacks ready-made installers for libraries like PyMuPDF. At least one laptop had Python 3.14, and CI was set to 3.11.

## Decision

Everyone and CI use **Python 3.12**. `pyproject.toml` sets `requires-python = ">=3.12"` and ruff's `target-version = "py312"`; CI and `TEAM_SETUP.md` use 3.12.

## Consequences

- One version everywhere, with wide library support.
- Anyone with a different version must install Python 3.12 alongside it (`py -3.12` on Windows, `python3.12` elsewhere).
